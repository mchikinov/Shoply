# Приложение Shoply

## Запуск

Нужен Python 3.10+. Сторонние серверные зависимости не требуются.

Из этой папки: `python3 backend/server.py`. Из корня репозитория: `python3 website/backend/server.py`.

На macOS можно открыть scripts/start.command двойным кликом. Оставьте окно сервера открытым. Адрес магазина — http://127.0.0.1:8765/, админка — http://127.0.0.1:8765/admin.html.

При первом входе задайте собственный логин и пароль (минимум 10 символов). Администратор один, встроенных учётных данных нет.

public/index.html можно открыть двойным кликом для просмотра каталога. Заказы и админка работают только через HTTP-сервер.

## Что работает

- 22 демо-товара, поиск, открытые фильтры категорий и цены, сортировка.
- Отдельный экран/URL каждого товара с описанием, галереей и свободными свойствами.
- Корзина и количество; корзина сохраняется в браузере.
- ФИО, телефон, почта/самовывоз; адрес скрыт и не требуется при самовывозе.
- Кнопка «Оплатить» сохраняет заказ в SQLite, показывает номер и «Ожидает оплаты». Онлайн-оплата не подключена, доставка не рассчитывается.
- Админка: оформление, товары, заказы. Название/логотип/основные цвета/Telegram; создание, редактирование и удаление товаров, категории, фото, произвольные свойства; контакты и состав заказов, смена статуса.

PNG/JPEG/WebP до 6 МБ, до 12 фото на товар. Категории автоматически попадают в фильтры. Флажок «Демонстрационный товар» управляет демо-маркировкой.

## Разделение кода

backend/server.py содержит сервер и API. public содержит только публичные страницы и ресурсы. CSS — public/assets/css, JavaScript — public/assets/js, изображения — public/assets/images, шрифты — public/assets/fonts. Сервер не раздаёт исходники backend, базу, тесты или материалы Codex.

## Данные и резервное копирование

SQLite: var/data/shoply.sqlite3. Фотографии владельца: public/assets/uploads. Обе директории исключены из Git. В свежем клоне создаётся чистый магазин без заказов и администратора.

Для резервной копии остановите сервер и скопируйте обе директории. Переносите базу и фотографии вместе. Локальная копия базы до реорганизации сохранена рядом как shoply-before-restructure.sqlite3; она также не входит в Git.

Переменные окружения: SHOPLY_PORT (по умолчанию 8765), SHOPLY_DATA_DIR (каталог SQLite). Сервер слушает только 127.0.0.1. Публикация, HTTPS и реальная оплата — отдельный этап.

## Проверки

Из папки website:

```sh
python3 tests/test_shop.py
node tests/test_frontend.cjs
```

Первый тест запускает реальный API с временной SQLite; второй проверяет логику интерфейса с моделью DOM. Это не визуальный браузерный тест.

Условия лицензирования Inter — public/assets/fonts/Inter-LICENSE.txt. Фотографии демо-товаров синтетические; происхождение и промпты находятся отдельно в ../codex/materials.
