# Shoply

Универсальный интернет-магазин с каталогом, корзиной, оформлением заказа и админкой. HTML/CSS/JavaScript, Python 3.10+ и SQLite; без сборщика и сторонних серверных пакетов.

## Структура репозитория

```text
website/                     приложение магазина
  backend/server.py          HTTP API, вход администратора, SQLite
  public/                    единственная публичная директория
    index.html               витрина и путь заказа
    admin.html               админка
    assets/
      css/                   стили и дизайн-токены
      js/                    логика витрины, админки и демо-данные
      images/                изображения демо-товаров
      fonts/                 локальный Inter и его лицензия
      uploads/               пользовательские загрузки; исключены из Git
  tests/                     проверки API и логики интерфейса
  scripts/start.command      запуск на macOS
  var/data/                  локальная SQLite; исключена из Git
codex/                       инструкции, бриф, дизайн, проверки, скиллы,
                             промпты, оригиналы изображений и превью
.github/workflows/checks.yml  проверки GitHub Actions
```

## Запуск

Из корня репозитория:

```sh
python3 website/backend/server.py
```

На macOS можно открыть `website/scripts/start.command` двойным кликом.

- [Магазин](http://127.0.0.1:8765/)
- [Админка](http://127.0.0.1:8765/admin.html)

В новом клоне база и 22 демо-товара создаются автоматически. Единственного администратора создайте при первом открытии админки. Встроенного пароля нет. Открывайте магазин через сервер: file:// не поддерживает сохранение заказов.

## Проверки

```sh
python3 website/tests/test_shop.py
node website/tests/test_frontend.cjs
```

GitHub Actions запускает эти проверки при push и pull request. Тесты используют временную базу, без реальных заказов.

Репозиторий подготовлен для GitHub. Локальные база, учётная запись, заказы, загрузки, кэши и исторические копии исключены через .gitignore. Перед первым push проверьте `git status` и задайте URL своего репозитория. GitHub Pages не запускает Python/SQLite: рабочему магазину нужен серверный хостинг.

Онлайн-оплата пока не подключена. Магазин сохраняет заказ со статусом «Ожидает оплаты», доставка уточняется отдельно.
