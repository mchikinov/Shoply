# Проверка визуального образца Shoply

Объём: каталог для согласования оформления, не рабочий магазин.

Проверено: синтаксис catalog.js командой node --check; локальные ссылки CSS/JS и PNG существуют. Используются относительные пути. Демо-товары и цены подписаны. Нет отправки заказов и ложной оплаты. Фильтры реализованы открытой панелью; мобильная компоновка предусмотрена в CSS.

Ограничение: браузерная проверка заблокирована политикой доступа — разрешение на просмотр локального адреса отклонено. Внешний вид на 1440×900, 390×844 и 390×640, взаимодействия, клавиатура и консоль не проверены в браузере. Оценка готовности и независимая визуальная проверка не выполнены.

Остаток: визуальная проверка владельцем, согласование образца, затем рабочие страницы товара, корзины, оформления и серверная админка. В текущем образце корзина хранится только в памяти; подробности товара показаны в диалоге.


Расширение каталога: 22 уникальных идентификатора, 18 новых товаров; соответствие типа товара одному из четырёх фото задано отдельно от ID. Исправлено склонение счётчика (22 товара). Проверка синтаксиса JavaScript пройдена; визуальный просмотр не выполнялся.


Иллюстрация первого экрана: просмотрен JPEG 1536×1024, проверены предметы, фон, отсутствие надписей и свободное поле слева. HTML использует contain, чтобы сохранять предметы целиком; на телефоне текст и изображение идут последовательно. Браузерная проверка этого образца не выполнялась из-за ранее отклонённого доступа.


## Пять экранов: иллюстрации и HTML-образцы
Просмотрены пять готовых JPEG: без текста, светлая студийная серия, предметы внутри кадра. Проверены наличие всех локальных HTML/CSS/JS/image-ресурсов, пяти PNG/JPEG/промптов и синтаксис screen-previews.js.

Отдельный проверяющий статически обнаружил два дефекта: авторский display мешал скрывать адрес при самовывозе и ссылку оформления пустой корзины. Исправлены одним правилом [hidden]{display:none!important}; наличие правила перепроверено. Дополнительно фото лампы в каталоге и корзине унифицировано с карточкой товара.

HTML и CSS предусматривают телефон, короткое окно, клавиатурный фокус и noJS (пять экранов последовательно). Фактически в браузере эти состояния, взаимодействия и геометрия не проверены: ранее доступ к локальному браузерному адресу отклонён. Оценка визуальной готовности не выставляется. Рабочий магазин и сохранение заказов этим этапом не реализованы.

## Итоговый локальный магазин

Проверка требований до передачи: 22 товара, общая модель каталога/корзины, отдельный URL товара, оформление с ФИО/телефоном/доставкой, сохранение заказов, один администратор, три раздела админки, настройки/фото/свойства/категории/статусы.

Выполнено:
- `python3 tests/test_shop.py`: реальный HTTP-сервер с временной SQLite, 22 стартовых товара, закрытые административные API и база, проверка источника запроса, создание единственного администратора, вход с кириллическим логином, товары CRUD, загрузка PNG, оформление и Telegram, запрет некорректной ссылки, серверная цена вместо присланной клиентом, повторное оформление без дубля, сохранённая доставка при повторе, скрытие адреса самовывоза на сервере, смена статуса, неизменность состава заказа после удаления товара, перезапуск и сохранность базы, выход. Пройдено.
- `node tests/test_frontend.cjs`: моделирование DOM без браузера; переход к оформлению, редирект пустой корзины, неудачный запрос и повтор с тем же токеном, подтверждение и очистка корзины, неизменность суммы подтверждения при последующих покупках, запрет оформления при file://. Пройдено.
- Синтаксис Python/JavaScript, наличие локальных ресурсов index/admin и доступность работающего сервера/шрифта проверены.
- Реальный экземпляр магазина запускается на 127.0.0.1:8765, 22 товара, ни одного администратора ещё не создано. Тестовые покупатели и заказы создавались только во временной базе.

Независимый статический обзор выявил три ошибки: кириллический логин в compare_digest, токен повтора только в памяти, неверные сумма/доставка при повторе. Исправлены; целевая перепроверка отдельным проверяющим и тестами пройдена. Ранее найденные потеря фокуса количества и отправка формы без JS также исправлены в основном магазине.

Ограничения: браузерное отображение на 1440×900, 390×844, 390×640, 1920×1080, touch, клавиатура в реальном браузере и консоль не проверены. Ранее браузерный доступ отклонён; запрет не обходился. Поэтому визуальная приёмка и оценка по 10-балльной шкале не заявляются. Платёжная система, хостинг, остатки и варианты не входят в этот этап.


## Подготовка GitHub и реорганизация
Приложение перенесено в website/, материалы Codex в codex/. Проверены все относительные HTML/CSS-пути магазина и превью, запуск API из нового backend/server.py, шрифты и публичные ресурсы, запрет чтения backend/var/codex через HTTP. API-интеграция и frontend-тесты пройдены после переноса.

Существующая база сохранена в website/var/data; перед миграцией путей создана её локальная копия. База, загрузки, архивы, секреты окружения и кэши исключены из Git; это проверено правилами ignore. GitHub Actions настроен, но удалённый CI ещё не запускался. Публикация репозитория не выполнялась. Браузерная визуальная проверка не повторялась; изменений композиции не было.
