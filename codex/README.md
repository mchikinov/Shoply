# Рабочие материалы Codex

Эта папка отделена от приложения. Она не раздаётся HTTP-сервером и не нужна для запуска магазина.

- AGENTS.md — исходные инструкции среды.
- .agents/skills/ — локальные скиллы; относительные ссылки внутри сохранены.
- BRIEF.md, DESIGN.md, REFERENCES.md, SITEMAP.md — требования и направление.
- REVIEW.md, HANDOFF.md — проверки и состояние проекта.
- previews/ — визуальные HTML-образцы; используют публичные ресурсы из ../../website/public.
- materials/ASSETS.md — реестр материалов.
- materials/source/ — оригиналы генераций и точные промпты.
- archive/ — ранние версии, исходная среда и примеры. Сохранены локально, исключены из Git.

Для дальнейшей работы сначала читайте AGENTS.md, BRIEF.md, DESIGN.md и HANDOFF.md здесь. Файлы приложения находятся в ../website. Исторические записи проверок могут содержать старые относительные пути; актуальная карта — HANDOFF.md.
