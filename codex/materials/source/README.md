# Материалы вашего сайта

Положите то, что уже есть; Codex поможет определить остаток.

| Папка | Что положить |
|---|---|
| texts/ | Описание проекта, тексты, вопросы клиентов: TXT, MD, DOCX |
| photos/ | Исходные фото товара, места и процесса: JPG, PNG |
| logo/ | Логотип: SVG или прозрачный PNG |
| brand/ | Брендбук, цвета, шрифты с лицензиями |
| proof/ | Подтверждённые отзывы, цифры, разрешения на использование |
| media/ | Иллюстрации и видео: исходники, web-версии и промпты |

Ссылки на ориентиры и комментарии сохраняются в REFERENCES.md. План изображений и происхождение — ASSETS.md. Не кладите в папку секреты, избыточные персональные данные и материалы без права использования.
